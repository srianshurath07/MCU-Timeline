The MCU Timeline

Stage 2: Using CSS to add elements for styling & image accessibility

Description:
Stage 2 introduces responsive design and visual enhancements to the MCU Timeline App. The focus of this stage is to ensure the timeline is visually engaging and device-friendly.

This stage builds upon the static HTML skeleton by integrating embedded CSS for layout, styling, and device adaptability. 


Key Enhancements:

Responsive Layout with Flexbox:
  - Timeline events now use Flexbox for layout.
  - On smaller screens, content stacks vertically for better readability.

Embedded Styling:
  - All CSS is included directly within the `<style>` tag in the HTML file.
  - Uses named colors (e.g., `crimson`, `midnightblue`, `dimgray`) for clarity and accessibility.
  - Font family restricted to `Arial`, `Times New Roman`, and `sans-serif`.

Improved Visual Hierarchy:
  - Event markers added using pseudo-elements for visual cues.
  - Box shadows and borders enhance readability and separation of timeline entries.
